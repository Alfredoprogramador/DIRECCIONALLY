# DIRECCIONALLY
É um site institucional premium + branding digital + preparação para tráfego pago.

## Estrutura

- `index.html`: página institucional premium com seções estratégicas
- `styles.css`: identidade visual sofisticada e responsiva
- `script.js`: interações leves e melhoria de UX

## Configuração de tracking

O projeto já inclui a estrutura para:

- Google tag (gtag.js) com IDs de exemplo
- Meta Pixel com ID de exemplo

Substitua os IDs de exemplo pelos IDs oficiais da conta antes de publicar.
